# 🚀 Kubernetes Self-Healing App Demo

This project demonstrates Kubernetes **self-healing capability** using a simple web application deployed on Minikube.

---

## 📌 Project Overview

A web application is deployed using Kubernetes with:

- Deployment (3 replicas)
- ClusterIP Service
- NodePort Service
- Auto-healing using ReplicaSet
- Chaos testing using shell script

---

## 🛠️ Tech Stack

- Kubernetes
- Minikube
- Docker (nginx demo image)
- kubectl
- Bash scripting
